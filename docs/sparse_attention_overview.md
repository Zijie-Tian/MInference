# Sparse Attention Overview

## 项目概述

MInference 是一个用于加速长上下文 LLM 推理的库，通过稀疏注意力机制将 O(n²) 的注意力计算降低到 O(n×k)，在保持精度的同时大幅提升推理速度。

---

## 稀疏模式类型

**模式对比:**
| 模式 | 描述 | 使用场景 |
|-----|------|---------|
| Vertical-and-Slash | 垂直列 + 对角线条带 | 大多数 head 的主要模式 |
| Block Sparse | 块级稀疏 | 注意力聚集的 head |
| Streaming/A-shape | 滑动窗口 + 初始token | 局部 + BOS 注意力的 head |

## 稀疏模式的来源

### 模式搜索（Pattern Search）

**代码位置**: `minference/modules/minference_forward.py:129-227`

**搜索过程:**
```
+------------------------------------------+
| 输入: Q, K tensors                        |
+------------------------------------------+
                ↓
+------------------------------------------+
| 对每种模式类型测试多个参数配置:            |
| - stream_llm: 滑动窗口大小                |
| - vertical_and_slash: vertical_size, slash_size |
| - block_sparse: 块大小                    |
+------------------------------------------+
                ↓
+------------------------------------------+
| 评估指标: 最后2500个token的注意力权重分布  |
| 选择质量分数最高的模式                    |
+------------------------------------------+
                ↓
+------------------------------------------+
| 输出: 每个head的最优模式配置              |
+------------------------------------------+
```

**搜索特点:**
| 特点 | 描述 |
|-----|------|
| 搜索时机 | Prefill 阶段 (`is_search=True`) |
| 搜索粒度 | 每个 head 和 layer 独立 |
| 结果存储 | JSON 配置文件 |

### 预计算配置文件

**位置**: `minference/configs/`

**配置文件结构:**
```
[
  {                                          // Layer 0
    "0": ["vertical_and_slash", 512, 2048, 0.9623],  // Head 0
    "1": ["vertical_and_slash", 512, 2048, 0.9543],  // Head 1
    ...
  },
  {                                          // Layer 1
    ...
  },
  ...
]
```

**配置格式:**
| 字段 | 位置 | 含义 |
|-----|------|-----|
| 模式类型 | [0] | "vertical_and_slash", "block_sparse", "streaming" |
| vertical_size | [1] | vertical 列的数量 |
| slash_size | [2] | slash 对角线的数量 |
| 质量分数 | [3] | 该配置的注意力覆盖率 |

## 性能特点

**性能数据:**
| 序列长度 | 稀疏度 | 加速比 |
|---------|--------|--------|
| 4,096 | ~27% | ~5x |
| 8,192 | ~15% | ~9x |
| 16,384 | ~8% | ~15x |
| 32,768 | ~5% | ~27x |

**稀疏度定义:**
```
稀疏度 = 计算的元素数 / 完整Causal元素数

完整Causal元素数: N × (N+1) / 2
稀疏元素数: num_vertical × N + num_slash × block_size × N
```

**性能特征:**
| 稀疏度 | 保留信息 | 典型加速 |
|-------|---------|---------|
| 5-10% | 90%+ | 10-30x |
