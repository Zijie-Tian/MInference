# Vertical-and-Slash Pattern

## 两种模式的含义

**模式对比:**
| 模式 | 形状 | 捕捉的信息 | 内存访问模式 |
|------|------|-----------|-------------|
| Vertical | 垂直列 (││) | 全局重要token（BOS、关键词） | Gather（散点访问） |
| Slash | 对角线 (╲╲) | 局部上下文（最近的token） | Coalesced（连续访问） |

**注意力矩阵分解:**
```
完整 Causal Attention:          Vertical-Slash 稀疏:
+---------------------------+   +---------------------------+
|■                          |   |■ ■   ■                    |
|■ ■                        |   |■ ■   ■ ■                  |
|■ ■ ■                      |   |■ ■   ■ ■ ■                |
|■ ■ ■ ■                    |   |■ ■   ■   ■ ■              |
|■ ■ ■ ■ ■                  |   |■ ■   ■     ■ ■            |
|■ ■ ■ ■ ■ ■                |   |■ ■   ■       ■ ■          |
+---------------------------+   +---------------------------+
 O(N²) 元素                      O(N×k) 元素
                                 ↑       ↑
                              Vertical  Slash
```

## Slash 模式的提取

### 对角线在注意力矩阵中的含义

**对角线索引定义:**
```
注意力矩阵 [query_pos × key_pos]:
        k0   k1   k2   k3   k4   k5   k6   k7
      +----------------------------------------+
  q0  | d=0                                    |
  q1  | d=1  d=0                               |
  q2  | d=2  d=1  d=0                          |
  q3  | d=3  d=2  d=1  d=0                     |
  q4  | d=4  d=3  d=2  d=1  d=0                |
  q5  | d=5  d=4  d=3  d=2  d=1  d=0           |
  q6  | d=6  d=5  d=4  d=3  d=2  d=1  d=0      |
  q7  | d=7  d=6  d=5  d=4  d=3  d=2  d=1  d=0 |
      +----------------------------------------+

d = query_pos - key_pos（相对距离）
```

**对角线属性:**
| 对角线 d | 含义 | 矩阵中的位置 |
|---------|------|-------------|
| d=0 | 自注意力 (q[i] → k[i]) | 主对角线 |
| d=1 | 前一个token (q[i] → k[i-1]) | 第一条次对角线 |
| d=N | N个token之前 (q[i] → k[i-N]) | 第N条次对角线 |

### 核心函数 `sum_all_diagonal_matrix`

**代码位置**: `minference/modules/minference_forward.py:110-116`

**as_strided 变换过程:**
```
输入: 注意力矩阵 (4×4)           输出: 对角线对齐矩阵
      k0   k1   k2   k3                d3   d2   d1   d0   d-1  d-2  d-3
    +--------------------+           +--------------------------------+
 q0 | a    -    -    -   |        q0 | 0    0    0    a    -    -    - |
 q1 | e    f    -    -   |  -->   q1 | 0    0    e    f    -    0    0 |
 q2 | h    i    j    -   |        q2 | 0    h    i    j    0    0    0 |
 q3 | k    l    m    n   |        q3 | k    l    m    n    0    0    0 |
    +--------------------+           +--------------------------------+
                                                ↓ 沿行求和
                                     [k, h+l, e+i+m, a+f+j+n, -, -, -]
                                      ↑              ↑
                                    d=3 求和      d=0 求和（主对角线）
```

**Stride 计算:**
| 参数 | 值 | 含义 |
|-----|-----|------|
| 输入形状 | (b, h, n, m) | batch, heads, queries, keys |
| 填充后形状 | (b, h, n, 2n+m) | 两侧各填充n个零 |
| 输出形状 | (1, 1, n, n+m) | n行, n+m条对角线 |
| Stride | (1, n*(2n+m), 2n+m+1, 1) | 每行跳过2n+m+1来对齐对角线 |

### Slash 模式提取的完整流程

**代码位置**: `minference/modules/minference_forward.py:381-396`

**发现过程:**
```
Step 1: 选择探针 Query（最后64个）
+--------------------------------------------------+
| 完整序列: [t0, t1, ..., t_{n-65}, t_{n-64}, ..., t_{n-1}] |
|                                   ↑─────────────────────↑ |
|                                      探针区域 (64个)       |
+--------------------------------------------------+

Step 2: 计算探针注意力
+--------------------------------------------------+
| Q_probe [64 × head_dim] × K [seq_len × head_dim]ᵀ |
|                    ↓                               |
| 注意力分数 [64 × seq_len]                          |
+--------------------------------------------------+

Step 3: 提取模式
+--------------------------------------------------+
| Vertical: 沿query维度求和 → [1 × seq_len]         |
|           选择 top-k 列                            |
|                                                   |
| Slash: sum_all_diagonal → [1 × seq_len]          |
|        选择 top-k 对角线                           |
+--------------------------------------------------+
```

**模式提取汇总:**
| 模式 | 操作 | 输出形状 | 选择方式 |
|-----|------|---------|---------|
| Vertical | `attn.sum(dim=-2)` | [1, seq_len] | Top-k 列索引 |
| Slash | `sum_all_diagonal(attn)` | [1, seq_len] | Top-k 对角线索引 |

## Vertical 模式的提取

**代码位置**: `minference/modules/minference_forward.py:387-389`

**计算过程:**
```
注意力矩阵 [64 × seq_len]:
+------------------------------------------+
|  a0   a1   a2   a3   ...  a_{n-1}        |  q[-64]
|  b0   b1   b2   b3   ...  b_{n-1}        |  q[-63]
|  c0   c1   c2   c3   ...  c_{n-1}        |  q[-62]
|  ...                                      |
+------------------------------------------+
            ↓ sum along query dimension
+------------------------------------------+
| Σa0  Σa1  Σa2  Σa3  ...  Σa_{n-1}        |  列重要性分数
+------------------------------------------+
            ↓ select top-k
+------------------------------------------+
| vertical_idx = [col3, col17, col45, ...] |  重要列的索引
+------------------------------------------+
```

**原理**: 沿 query 维度求和，得到每个 key 被关注的总权重，选择权重最高的 k 个 key 位置。
